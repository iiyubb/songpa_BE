## 학습 주제: 팀 프로젝트 - 냉파 마스터
---

### 학습 내용

- 냉파 마스터 기획 추가 및 수정
- 화면 설계서 작성
- 사용자 흐름도 작성

---

### 느낀 점
기능을 코드로 구현하기 전에 사용자가 실제로 어떤 경로로 움직이는지를 머릿속에서 한 번 검증할 수 있었다. 백엔드 관점에서 API 엔드포인트만 떠올렸을 때는 보이지 않던 예외 경로(로그인 실패, 입력값 누락, 뒤로 가기 등)가 흐름도를 그리면서 드러났고, 화면 단위로 쪼개보니 어떤 데이터가 어느 시점에 필요한지가 명확해졌다.

---

### 활용 방안
사용자 흐름도를 기준으로 API 명세를 역산할 수 있다. 각 화면 전이마다 필요한 엔드포인트를 매핑해두면 누락 없이 REST API를 설계하고, Bean Validation으로 막아야 할 입력 케이스도 흐름상의 분기에서 미리 도출할 수 있다.

화면 설계서를 프론트엔드와의 협업 계약서로 활용한다. 화면별 필요 데이터와 응답 구조를 합의해두면 응답 DTO 형태에 대한 인식 차이를 줄이고, 통합 단계의 수정 비용을 낮출 수 있다.
